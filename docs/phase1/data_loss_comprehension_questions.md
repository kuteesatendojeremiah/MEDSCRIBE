# Data-loss comprehension check (Blueprint §14, Phase 1 exit criterion)

Target: at least 9 of 10 test clinicians answer all four correctly after using the prototype with the fictional Kato case.
This must be run with real people; the build cannot produce the result.

1. If you close or refresh this tab before downloading, what happens to the draft note?
2. Does Mediscribe keep a copy of the note or recording after you press "End session & clear"?
3. If you edit the note after approving it, what happens to the approval?
4. Where should the approved document be filed?

Expected: (1) it is lost and cannot be restored; (2) no; (3) approval is cleared and the note must be previewed and approved again; (4) in the patient's official record (paper file or EMR).
